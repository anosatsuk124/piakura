# Compare another arrangement

Use when the user supplies or requests a reference arrangement, or when an
external score is already authorized evidence. Independent mix-only trials
keep these references with the evaluator, outside the trial input.

Record the source page, downloaded file hash, duration, tempo map, pitch range,
instrumentation and track/channel layout. Link the source page in reports.
Use Go sidecars for MIDI note analysis. A single piano track can contain both
hands and several voices; neither a MIDI channel nor a fixed pitch split proves
a hand or melody assignment. Review voice roles over the phrase and retain
ambiguity. Automatic difficulty results with inferred hands are diagnostic.

Map matching motifs, pickups and arrivals across both performances. Identify
omitted/reordered sections and octave choices separately. Preserve original
timing and document phrase anchors; never force a full-song stretch through a
different edit or use candidate-specific alignment to maximize note matches.
If a passage cannot be mapped, compare its musical function qualitatively and
leave note-level accuracy unmeasured.

Compare structural melody and bass first, then harmonic rhythm and quality,
voice leading, register, texture, dynamics, articulation, pedal and endings.
Record concrete pitch/time examples and why the difference matters. Distinguish
source-transcription error, an arrangement weakness, a defensible alternative
and an unresolved question. Check a proposed source correction against the
specified recording; another pianist's octave, fill, reharmonization or timing
is not automatically a source note. Pedal/event counts and velocity ranges are
diagnostics, not quotas to imitate.

Use the same piano renderer and gain for matched excerpts, preserving each
performance's expression. Include neighboring context and releases. Compare
musical roles within the requested difficulty, rather than rewarding the
reference's larger note count. Apply `midieval` only to independently mapped,
role-compatible passages; label its alignment, coverage and interpretation.

Keep piece-specific notes, alignment maps and correction examples in ignored
working evidence. Improve the skill with the general decision that failed.
A rerun on the same piece is a same-piece retest, even when the new agent cannot
see the reference. It does not demonstrate transfer to other recordings.
