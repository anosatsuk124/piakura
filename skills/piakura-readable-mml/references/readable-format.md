# Readable SakuraMML

`--mode readable`は、人が読んで編集するための表記を出す。Pretty/Canonicalと違い、宣言した拍の時計へ量子化するため、揃っていない入力では元の時刻が変わる。どれだけ動いたかは`--readable-report`のJSONに出る。今後の編曲はこの表記を正本にする。

```text
// @section verse-a (20.40 s)
o5 l8 r4 d4. d c+ d& // 13: D
o5 l8 d4. r r d e e // 14: Bm7?
Sub{o4 l2 g a} o5 l8 e f g a b4 >c4& // 15: C
```

時計:

- `--clock score`（既定）: 入力のテンポと拍子をそのまま使い、tick 0を`--first-bar`（既定1）の小節頭とする。拍子変更は未対応でエラー。
- `--clock grid`: 録音の拍で数える。`--grid-bpm`、小節1の頭の秒`--grid-downbeat`、`--beats-per-bar`/`--beat-unit`を与える。採譜MMLの`Tempo()`は秒の時計で拍子ではないため、採譜・候補MIDIにはこちらを使う。`--offset-seconds`は入力のtick 0の録音上の秒。
- 出力は`TimeBase(480)`。tick 0は入力tick 0（か最初の音）を含む小節の頭で、拍頭より前の音は小節0などの弱起になる。その秒はreportの`offset_seconds`（piakura-reviewのレイヤーに付ける値）。gridのテンポは、曲末までのずれが15 ms未満なら整数`Tempo(150)`、そうでなければ小数`Tempo={150.01}`で書く。

表記:

- 1小節1行。行末に`// 小節: 和音`、区間は見出し`// @section label (秒)`（`--sections`の配列か、review spec.jsonと`--section-set`）。同じ小節が続くと`[n …] // a-b`にたたむ（`--no-fold`で無効）。
- 発音はトラックごと・拍ごとに16分（`--subdivision 8|4`で粗く）か8分3連の格子へ寄せる。3連は内側の2点以上に発音があり、二乗誤差の減りが`--triplet-penalty`（拍²、既定0.004）を超える拍だけ。2拍にまたがる4分3連も同じ判定をする。採譜の約10 msの揺れで16分が3連にならないようにしている。`--no-triplets`で無効。
- 長さは音価（`1 2. 2 4. 3 4 8. 6 8 12 16 24 48`、他は`^`でつなぐ）。各声部で2回以上使う付点でない最頻値を`l`にする。8分3連1拍分の単音・休符は`{c r e}4`（群の長さを必ず書き、和音は入れない）。
- 同時に始まり同時に終わる音は和音`'ea>c<'`。和音の中で上げたオクターブは閉じる前に戻し、前後のオクターブを変えない。
- 重なる音は声部に分け、最も多い声部を本線、残りを同じ行の`Sub{o.. l.. …}`にする。TRは入力トラックのまま（ピアノのTR1=右手、TR2=左手を保つ）。`Sub`の中では`v`/`q`を変えず、`Sub`の後で本線の`o`/`l`を書き直す（上流の`Sub`は時刻だけを戻し、`o/l/v/q`が漏れる）。
- 本線の単音が小節線をまたぐときは`f2&`→次の行の`f4`のタイにする。閉じる音は次の行で最初に実行する音で、その区間に同じトラックの他の声部の発音があればタイが切れてポルタメントになるため、その音と小節をまたぐ和音は`Sub`へ移して小節をはみ出させる。行頭の`^`は直前行の末尾コメントと組むとエラーになるので使わない。
- `q`はトラックに1つ。レガートな音の「発音長/次の発音までの間隔」の最頻値（5刻み、50〜100）。それより明らかに短い音は自分の音価と休符で書く。同じチャンネル・音高の次の発音より前に必ず離す。`--gate exact`は合わない音に`c4,%432`を付ける。
- `v`は小節の中央値が8以上動いたときだけ行頭に書く（`--velocity track|exact`も選べる）。
- 調はKrumhansl-Kesslerで推定してヘッダにコメントし、臨時記号の向き（`c+`か`d-`）に使う。`KEY()`は上流では移調なので書かない。和音名は全トラックの書いた長さから小節ごとに推定し（半小節に分けるのは両方が明確で大きく合うときだけ）、確信が低いものに`?`を付ける。旋律1本だけの入力には付けない。`--chords names|roman|both|none`。
- 書かないもの: コントローラ、pitch bend、テキストメタ、SysEx、End Of Track用の予約Marker、release velocity。数はreportの`dropped`。

reportの主な項目: 時計と書いたテンポのずれ`drift_ms`、`offset_seconds`、音数（統合・ユニゾン・詰め・装飾音の移動・声部の詰め）、発音と終わりのずれ`onset_ms`/`end_ms`（p50/p95/max/符号付き平均）、`velocity`の差、3連の拍数、和音の`?`数、ずれの大きい20音（`worst`）、16分の半分以上動いた全音（`moved`）、統合・詰め・装飾音の移動の一覧（`events`、音符はtrack/on_order）。符号付き平均が16分の1/4を超えると、小節頭か時計の誤りとしてwarningを出す。

不変条件（テストで確かめている）: 予測した音（`Result.Predicted`）とその行が、上流のコンパイル結果と`--note-lines`に一致する。出力を`--clock score --first-bar <first_bar>`で読み直すと同じ文字列になる。格子に乗った入力では音高と発音が一致し、`--gate exact --velocity exact`では終わりとvelocityも一致する。
